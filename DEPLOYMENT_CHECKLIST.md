# Deployment and final submission checklist

- [ ] Create and activate a clean Python 3.11 virtual environment.
- [ ] Install `requirements.txt`.
- [ ] Run download, EDA, training, lint, and tests successfully.
- [ ] Review `artifacts/model_comparison.csv`; transfer actual values into the report.
- [ ] Review EDA/model plots; include them in report or appendices.
- [ ] Open MLflow UI and capture experiment runs.
- [ ] Push to your own GitHub repository; enable Actions; capture successful workflow.
- [ ] Build and run Docker after training; test `/health`, `/predict`, `/metrics`.
- [ ] Deploy to Minikube/Docker Desktop or cloud; verify pods and service.
- [ ] Add real repository URL, API URL or local access instructions, screenshots, and demo video.
- [ ] Fill student name and ID in the report.
- [ ] Read through the code and be prepared to explain preprocessing, model selection, metrics, CI, and deployment.
